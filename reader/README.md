# 払戻読取 7.5.2

MK払戻とは独立した `/reader/` の写真読取・払戻計算ページです。JR北海道内の登録駅・経路を使います。既存MK払戻の画面・運賃データは変更していません。

## 使い方

1. カメラ撮影または保存済み写真を選ぶと端末内で読み取ります。横向きに大きく写すと読みやすくなります。縦向きの撮影も可能です。
2. 「計算する券種・商品」、駅名、合計発売額、料金内訳、座席区分を券面と照合します。対象外判定でも入力欄は消えず、誤判定を選び直せます。発着・経由・中止・市内実乗降駅、3種類の料金、割引種別は券種・使用状態にかかわらず常に編集できます。
3. 「読取文字を確認・修正する」で文字を直し、「修正した文字を入力欄に反映」することもできます。低確度の読取記録は参考として別に表示します。
4. 使用状態と払戻理由を選び、必要な条件を確認します。確認チェックで計算し、入力を変えると確認と結果を解除します。

旅客区分は大人、通常乗車券の割引は割引なし、払戻理由は「お客様都合（通常払戻）」が初期値です。理由は後から選び直せます。割引表示を検出して種別が不明・不一致の場合は空欄に戻して確認します。

札幌市内を読み取った側の元券の発駅・着駅と、市内の実際の乗車駅・下車予定駅には「札幌」を自動入力します。市内チェックを手動で入れた場合も対応する両方の駅名欄に入力します。駅名欄は後から編集でき、使用状態や払戻理由を変更しても手入力を上書きしません。実際の乗降駅が札幌以外の場合は修正してください。

駅名の一部を入力すると画面内に最大8件の候補を表示します。「さ」で「札幌」、「しま」で「島松」、「おしゃ」で「長万部」が表示されます。登録309駅すべての読み仮名を使い、ひらがな・カタカナの変換中にも候補を更新します。候補には駅名と読み仮名を表示し、クリック／タップ、上下キー＋Enterで選べます。経由駅は最後に入力している駅の候補を表示し、前の駅を残します。市内の実乗降駅は札幌市内の候補を使います。

読み仮名は[JR北海道の駅情報検索](https://www.jrhokkaido.co.jp/network/station/station.html)が公開する `csv/station.csv` を2026-10-10に照合して `data/station-readings.json` に収録しました。元の登録駅・計算用経路は増減していません。

選択した券種に対応する内訳を変更すると、必要な金額がそろった時点で合計発売額を更新します。単独券は合計発売額と対応する内訳が連動します。割引欄にはトクだ値も追加し、券種・商品と連動します。未使用払戻では入力済みの実発売額を使い、選択した割引で再割引しません。

以下は7.4.2までの変更です。

- トクだ値の手数料を乗車券・特急券それぞれの実発売額から計算。各手数料の10円未満切捨て・各最低手数料を適用してから合計し、結果にも券種ごとの手数料・払戻額・計算式を表示。
- トクだ値でも運賃・特急料金の内訳を必須にし、内訳合計と発売額の一致を検証。合計額だけでは計算しません。
- 対象外判定によるフォーム非表示を廃止。券種・商品を手動修正でき、読めた駅・発売額は対象外券でも反映。
- 読取と文字修正を同じ反映処理に統一。席番・座席区分・内訳を結果欄と入力欄へ反映。
- 元写真と濃さ調整の2回を必ず比較。不足時は薄い文字向けの補正で最大3回。
- 駅が不足する場合、読めた乗車日の上の駅名部分を最大2回追加読取。部分読取は駅名・市内表示だけに使い、近くの記号や数字で発売額・商品判定を上書きしません。
- 最大2000pxで処理し、小さい画像は最大2倍まで拡大。青成分・グレー成分の分布に応じてコントラストを補正。
- `内訳` が複数行になった場合、`乗車券運賃`・`特急料金`等のラベルも解析。合計一致を必須にし、内訳の並び順の違いだけでは不一致にしない。
- `乘→乗`、`內→内`、`网→網`等のOCR字形を補正。金額の不正な区切りや曖昧な文字は推測して数字に変換しない。
- 券種・金額・駅名・座席・割引率が食い違う場合は多数決で確定せず、確認入力へ戻す。
- 駅・金額・割引の修正欄を常時表示し、画面の文字サイズと狭い画面での折返しを改善。
- 発売額や払戻条件の確認は写真の入替え・再読取時に解除。割引なしの初期値はリセット後も維持。

## トクだ値の通常払戻

この版の計算対象は **受取後の紙券・乗車券＋指定席特急券セット1席分・未使用・指定列車の出発前** です。受取済み、使用状態、出発前は読取で自動確認しません。券面の実際の発売額と割引率を使います。

- 乗車券手数料：乗車券の実発売額×割引率の10円未満切捨て、最低220円。
- 特急券手数料：特急料金の実発売額×割引率の10円未満切捨て、最低340円。
- 各手数料を各内訳から控除して払戻額を計算し、最後に合計します。各内訳の払戻額は0円が下限です。
- トクだ値30は30％、トクだ値20は20％。運賃4,000円＋特急料金2,000円なら手数料1,800円／1,200円、払戻4,200円／4,800円。
- 提供写真の運賃3,380円＋特急料金2,060円・トクだ値30の場合、乗車券手数料1,010円＋特急券手数料610円＝1,620円、払戻3,820円。合計発売額に先に率を掛けてから切り捨てた1,630円とは異なります。
- 現行の商品名「トクだ値1・14・28等」は申込期限を表します。数字だけから1％・14％・28％と扱いません。割引率が読めなければ入力してください。
- 内訳が読めない場合は運賃と特急料金を入力してください。合計額から内訳を推測せず、合計が券面の発売額に一致してから計算します。
- えきねっと特典の受取前の320円や、通常指定席券の2日前340円／前日当日30％とは区別します。
- 紙券の払戻は駅窓口、出発時刻までかつ窓口営業時間内です。

前版は合計発売額だけに率を掛け、端数処理前の参考額を表示していました。この版から内訳ごとに手数料を計算して10円未満を切り捨てます。えきねっと公式の商品案内は割引率と最低手数料の内訳（乗車券220円＋特急券340円）を示しています。JR北海道旅客営業規則第237条の3は一葉の複数券種を各別に扱う原則、第273条は指定券手数料の10円未満切捨てを定めています。ただし、確認した公開の商品案内にはトクだ値の乗車券部分の端数処理を直接明記した記載はありません。内訳ごとの10円未満切捨てについては、下記の補足資料も照合して実装しました。

受取前・チケットレス特急券（トク割）・障害者割併用・料金のみ・グリーン・複数席／複数商品・使用開始後・乗り遅れ・運休の個別計算は対象外です。対象外でも読取内容の確認・修正はできます。通常乗車券の途中中止規則をトクだ値へ自動適用しません。

## 通常券の既存計算

- 普通片道乗車券：使用開始前は実発売額−220円。使用開始後のお客様都合は未使用101km以上を確認し、元券経路の既乗区間運賃と220円を控除。
- 自由席料金券・出発前の立席特急券220円、座席未指定券340円。指定席は2日前まで340円、前日・当日または該当する変更済指定券は30％（10円未満切捨て、最低340円）。
- 指定席特急券＋グリーン券一体券の同時払戻はグリーン料金部分の手数料のみ。乗車券部分は別に220円。
- 運休は事由発生前の購入・使用状況・対象列車／設備の利用不能等を利用者が確認。
- 札幌市内制度の一部、北斗の経由候補、学割・障害者割の既存条件は維持。他都市・その他の企画券・団体・往復／連続・定期・回数券・遅延のみ・送還等は個別確認。

## 開発・検証

```sh
node --test tests/*.test.mjs tests/refund.test.cjs
python3 -m http.server 8765
```

`http://localhost:8765/reader/` で確認します。カメラの実機確認はHTTPSの公開URLを使います。

実写真の加工・ブラウザベンチマークは `benchmarks/generate-degraded.mjs` と `benchmarks/browser-robustness.mjs` で再現できます。`benchmarks/package.json` のSharpと、開発環境のPlaywrightが必要です。写真・正解・読取結果はGitに含めず、別の作業フォルダに置いてください。JPEG/PNGの元画像と、任意のHEIC原本を次の形式で指定します。

```json
[{"name":"sample","file":"/absolute/path/sample.jpg","original":"/absolute/path/sample.heic","expected":{"from":"札幌","to":"長万部","price":"5440"}}]
```

```sh
node reader/benchmarks/generate-degraded.mjs /absolute/path/samples.json /absolute/path/fixtures
node reader/benchmarks/browser-robustness.mjs /absolute/path/fixtures/manifest.json /absolute/path/results.json
```

`READER_URL` で読取ページ、`READER_BROWSER` でChromium系ブラウザの実行ファイル、`READER_PLAYWRIGHT_MODULE` で既存のPlaywrightモジュールを指定できます。画質低下はぼけ0.75＋JPEG品質12、縮小は幅900px、ノイズは固定乱数の各色±18、暗さは各色38％、線は横2本＋縦1本、複合は幅1100px＋ノイズ＋明るさ55％＋JPEG品質35です。

7.5.0の検証：自動テスト72件と、上記実写真21条件がすべて通過しました。発着駅、発売額、券種、運賃・特急・グリーン料金欄、トクだ値率、発着側の市内チェック、座席区分の11項目を確認しています。今回の券面にグリーン料金はなく、空欄を保持する検証です。駅候補は全6欄、変換中のひらがな、複数経由駅、キーボード選択、390px幅・1280px幅で確認。写真3枚の結果は、実券写真全般の精度率を表すものではありません。

写真・読取文字はアップロード／永続保存しません。OCR Worker、WASM、約46MBのモデル、運賃データを同じサイトから取得し、端末内で処理します。完全オフライン起動は未対応です。モデルを変更・再学習した修正ではありません。

7.4.2の検証：自動テスト64件。内訳ごとの端数処理・個別最低手数料・不正／不足／不一致の内訳・正確な10円境界を追加検証しました。ブラウザでは提供HEICを再読取し、手入力なしで札幌（市内）→長万部、発売額5,440円、乗車運賃3,380円、特急料金2,060円、トクだ値30％、指定席を反映できました。未使用・出発前を仮定した計算テストで手数料1,620円・払戻3,820円を確認。20％・乗車券の最低手数料・内訳空欄／不一致／出発後の停止と、390px幅での計算式の折返しも確認しました。実券の現在の払戻可否を判定したテストではありません。

7.4.1では全券種・使用状態・払戻理由60通りの常時編集、駅候補、複数経由駅、内訳合計更新、割引選択を確認済みです。グリーン料金は提供券面にないため空欄です。提供写真1枚の結果は実券写真全般の精度率を表しません。7.4.0では人工きっぷ画像2枚の実OCR、券種訂正も確認しています。
