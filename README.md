# MK払戻

JR北海道の払戻計算支援Webアプリです。

## 初期版の対応範囲

- 314隣接区間データによる経路検索
- 営業キロ・換算キロの集計
- 普通運賃、自由席・指定席特急料金、グリーン料金の検索
- 使用開始前の基本的な払戻判定
- 通常の旅行中止（使用開始後）：中止駅から元券経路の未使用区間を自動抽出
- 通常普通乗車券の学割・障害者割引（Version 5.2の6選択肢）
- 定期券・回数券の既存計算
- 事故払戻（運休）：旅行開始前／開始後の乗車券・料金券、5日以上使用不能の定期券
- 定期券の事故払戻は、日額の1円未満切上げ後に日数を乗じ、最後に10円未満を切捨て
- 券面額・料金、手数料、払戻額、計算式、判定理由、経路明細の表示
- ライト／ダーク表示

## 現在の未対応範囲

- 事故払戻のうち、無賃送還、他経路乗車、不乗証明、定期券の有効期間延長
- 事故発生前の購入を確認できないケースの自動判定
- 普通回数乗車券、定期券の2区間以上使用不能、2・4・5箇月定期、特別な定期券・割引商品の個別計算
- 列車別・季節別料金
- 通常普通乗車券以外の割引、マスタにない割引条件

未対応項目は、誤計算を防ぐため自動計算対象外として表示します。

事故払戻の「事故発生前に購入済み」は初期値が「未確認／不明」です。標準定期券を計算する場合は、確認後に「はい（確認済み）」を選択してください。

## GitHub Pages公開

`Settings` → `Pages` → `Deploy from a branch` → `main` / `/(root)` を設定してください。

## 通常の旅行中止

「通常払戻」→「普通乗車券」で、元券の発駅・着駅・必要な経由駅を指定し、
「旅行中止（使用開始後）」と元券の割引種別を選び、中止駅を入力します。
有効期間内であることは券面で確認してください。

未使用区間の営業キロが101km以上の場合、元券発売額から既乗区間の運賃と220円を控除します。
既乗区間だけで元券の割引条件を満たす場合は割引運賃、満たさない場合は無割引運賃を控除します。
未使用区間の普通運賃は参考表示で、払戻額の計算基礎には使いません。101km未満は自動計算対象外です。
営業キロ・地方交通線換算キロ・運賃計算キロ・参照運賃表と計算式を結果に表示します。
同行が条件の割引には同一種類・同一区間を同時利用する確認が必要です。

割引条件は `data/discount_rules.json` とVersion 5.2を踏襲しています。
未定義の年齢・証明書などの制度条件は追加判定していません。
事故払戻では従来のmainの計算を維持し、この通常払戻の割引選択は使いません。
経路は入力した経由駅を結ぶ既存の営業キロ最短経路です。実際の券面経路に合わせて経由駅を入力してください。
詳しくは [実装ノート](TRAVEL_STOP_IMPLEMENTATION.md) を参照してください。
